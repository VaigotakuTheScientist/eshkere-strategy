Last updated: 2026-08-16

Status: **first operational inventory**. External opportunities were checked against official pages on 2026-08-16. Availability and terms can change; re-check before applying.

## Purpose and model

Centralize concrete resource opportunities and endogenous projects, then choose actions that relieve the financial bottleneck while building AI-safety career capital.

Keep three dimensions separate:

1. **Acquisition route:** Employment, Career Transition Grant, Project Funding, Support Program, or Project Revenue & Donations.
2. **Career path:** generalist/operations, field-building, communications, governance/policy, technical AI safety, entrepreneurship, or another path.
3. **Record type:** search cluster, existing project/activity, or concrete opportunity/application.

All tracked content is public. Useful application and strategic details are permitted; exclude private contact details, confidential conversations, third-party-confidential material, and details whose publication would create material risk.

## Financial screen

- **Minimum-stable screen:** roughly **SEK 18–20k net/month** or an equivalent combination of income, housing, and runway.
- **Comfortable screen:** roughly **SEK 24–26k net/month**.
- A lower financial return may still dominate if AI-safety value and career-capital gain are unusually high and the time cost is bounded.
- Project grants are not treated as stable personal income unless their terms explicitly fund time or living costs.

See `docs/FINANCES.md` for scenario assumptions.

## Endogenous project decision

Working architecture—not a claim about the current organization:

- **Safe AI Sweden** is the possible umbrella.
- **Field-building/community** is the mechanism.
- **Events** are the first testable delivery unit.
- **Media** is a later distribution experiment, not a separate priority yet.

### Safe AI Sweden — Opportunity-to-Action pilot

Audience hypothesis: Sweden-based people already seriously interested in AI safety who need a bridge from interest to a project, application, collaborator, or role.

- This week, define the **smallest concrete pilot**, intended output/result, evidence already available from current work, and any specific monetary bottleneck.
- Create a minimal budget only for costs that accelerate the concrete work; exclude general living costs and a generic laptop.
- Check for duplication with existing Swedish/Nordic work.
- If a specific cost is already blocking concrete work, apply to BlueDot Rapid immediately. If money is not yet the bottleneck, run the smallest useful pilot first and apply only when funding would accelerate something real.
- Keep Coefficient capacity-building funding as a possible larger route if evidence supports talent-building, professional networks, events/groups, or public-discourse work.
- Treat media as a later distribution test; expand only after a strong artifact shows signal.

Do not use arbitrary elapsed time as the funding trigger. This model remains falsifiable and avoids double-counting four vague project clusters as four independent organizations.
