# Eshkere Strategy financial inventory

Last updated: 2026-08-16

Status: **rough initial snapshot**. Unknown values are deliberately marked `TBD`; no figure here should yet be treated as a settled target.

## Purpose

Build the minimum financial model needed to remove financial pressure while preserving or increasing the founder's capacity to contribute to AI Safety. This is not an income-maximization exercise.

## Recording rules

- Use approximate **SEK ranges**, an `as of` date, and confidence (`high`, `medium`, `low`, or `TBD`).
- Distinguish `0`, `TBD`, and an expense paid directly by someone else.
- Record generic source labels rather than unnecessary identifying or account information.
- The tracked file is public, and the user has explicitly approved adding useful approximate personal financial ranges here.
- Avoid unnecessary precision; keep any particular value in the gitignored local `private/` directory if the user requests privacy or publication would create material risk without strategic value.

## Working calculation method

- `essential burn = sum of essential recurring expenses`
- `normal burn = essential burn + normal recurring additions`
- `monthly net burn = chosen burn basis − reliable monthly support`
- `usable liquidity = spendable liquid savings − committed near-term obligations`
- `current runway = usable liquidity ÷ positive monthly net burn`

If reliable support covers the chosen burn, report that savings are not currently being drawn down through the support's expected end date rather than calling runway infinite. Later calculations should use ranges and scenarios, not false precision.

## First intake

Collect recurring expense ranges first. Then collect the dated income/support schedule and liquid savings. Only after a preliminary burn and runway calculation should we estimate major one-off scenarios and choose target margins.
